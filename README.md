# 智能任务管理系统

基于 **Node.js(Express) + React(Vite) + Supabase** 的干净全栈任务管理应用。中文界面，简洁美观。

> 本版本为标准技术栈实现，不依赖任何第三方/豆包专属工具，可直接在本地运行或部署到 Vercel / Render。

## 功能

- ✅ 输入框 + 优先级下拉（高/中/低）添加任务
- ✅ 任务列表显示标题、优先级标签、完成状态
- ✅ 每条任务有「完成/未完成」切换按钮和「删除」按钮
- ✅ 按优先级筛选（全部/高/中/低）
- ✅ 任务按创建时间倒序显示
- ✅ 已完成任务标题加删除线
- ✅ 数据持久化存储（Supabase），刷新不丢失

## 技术栈

- 后端：Node.js + Express + @supabase/supabase-js
- 前端：React 18 + Vite
- 数据库：Supabase（PostgreSQL）

## 快速开始

### 1. 配置 Supabase

Supabase 中需存在 `tasks` 表，建表 SQL：

```sql
create table if not exists tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  priority text check (priority in ('高','中','低')) not null default '中',
  completed boolean default false,
  created_at timestamptz default now()
);

alter table tasks enable row level security;
drop policy if exists "allow all" on tasks;
create policy "allow all" on tasks using(true) with check(true);
```

复制 `.env.example` 为 `.env`，填入你的 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY`。

### 2. 安装依赖并运行

```bash
npm install
npm run dev
```

- 前端：http://localhost:5173
- 后端 API：http://localhost:3001

### 3. 生产构建

```bash
npm run build
npm start        # NODE_ENV=production，Express 托管 dist，单端口 http://localhost:3001
```

## 部署

### Render（推荐）

创建 Web Service，Build Command 填 `npm install && npm run build`，Start Command 填 `npm start`，
添加环境变量 `SUPABASE_URL`、`SUPABASE_ANON_KEY`。

### Vercel

使用 `vercel.json`（见仓库内文件）：前端由 Vite 构建为静态资源，后端走 `api/index.js` Serverless 函数。
1. 在 Vercel 导入仓库，选择 Vite 框架
2. 在项目 Settings → Environment Variables 添加 `SUPABASE_URL`、`SUPABASE_ANON_KEY`
3. 部署后即可访问（API 与前端由同一部署提供）

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/tasks?filter=全部\|高\|中\|低` | 任务列表（创建时间倒序） |
| POST | `/api/tasks` | 添加任务 `{title, priority}` |
| PATCH | `/api/tasks/:id` | 切换完成状态 `{completed: bool}` |
| DELETE | `/api/tasks/:id` | 删除任务 |
